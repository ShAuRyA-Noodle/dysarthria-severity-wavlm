# ATD — Articulatory Trajectory Deviation

## Thesis
Pre-trained SSL models (WavLM-Large) learn a manifold of human articulatory execution.
Neurotypical speakers trace tight, consistent trajectories through this manifold for any given word.
Dysarthric speakers trace erratic, high-variance paths.
The geometry of these paths **IS** the dysarthria — no fine-tuning required.

**Target venues:** INTERSPEECH 2026 / ICASSP 2027 (A★/A-ranked)

## Key Technical Decisions — NEVER CHANGE
1. Primary SSL model: **WavLM-Large** (`microsoft/wavlm-large`) — ALWAYS FROZEN
2. Never fine-tune any SSL model
3. Primary analysis layer: **Layer 9** (validate experimentally)
4. Trajectory alignment: **DTW** via `fastdtw`
5. Reference trajectories: ONLY from control speakers (severity=0)
6. PCA reduction: **64 dims** before DTW
7. All embeddings: `.npy` files indexed in `ssl_index.json`
8. Splits: defined once in `splits.json`, never changed
9. Random seed: **42** everywhere
